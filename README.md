# Ritesh J — Full Stack Developer Portfolio

A premium one-page portfolio built with React + Vite + CSS animations.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Customize before publishing

Open `src/App.jsx` and replace:

- `projects` with your real projects, screenshots, links and metrics.
- `reviews` with real client testimonials.
- Contact email.
- LinkedIn / GitHub / Fiverr / Upwork links.
- Any project descriptions and company details you want to change.

The hero developer character is CSS-based, so the project works without downloading a 3D model. It is intentionally designed as a lightweight 3D-style visual and can later be replaced with a real GLB/Three.js character if desired.
